  "explanation": "This program creates a 1x8, 1-bit-per-pixel TIFF encoded with CCITT Group 4 (T.6). Group 4 encoding is 2D for every row, so the first encoded row uses a reference line rp that is all white. With width (bits) == 8, the initial computation in Fax3Encode2DRow sets b1 to finddiff(rp, 0, bits, 0), which returns bits when rp is uniform white. On the next line, b2 = finddiff2(rp, b1, bits, PIXEL(rp, b1)) evaluates the PIXEL macro unconditionally with b1 == bits. Since PIXEL accesses rp[b1 >> 3], this reads rp[1] when the row has only 1 byte (bits/8 == 1), causing a 1-byte out-of-bounds read. Building and running this with -fsanitize=address will report the OOB read at the vulnerable line."
